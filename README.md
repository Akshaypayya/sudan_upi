A modern, fast, and secure Unified Payments Interface (UPI) mobile application designed for Sudan's digital payment ecosystem. Sudan UPI empowers users with instant peer-to-peer transactions, utility bill settlements, mobile recharges, and merchant payments in a sleek, user-friendly interface.

---

## 🌟 Key Features

- **⚡ Instant P2P Payments**: Send and receive money seamlessly using phone numbers, UPI IDs, or QR codes with instant transaction confirmation.
- **👥 Quick Contact Transfers**: One-tap quick pay to frequent contacts with visual avatars.
- **💡 Utility Bill Payments**: Pay electricity, water, and essential public utilities directly from the app.
- **📱 Mobile Airtime & Data Recharge**: Quick recharge options across local telecommunications networks.
- **✈️ Travel & Ticket Bookings**: Integrated flight and travel service payment options.
- **🎁 Rewards & Cashback Hub**: Dynamic promotional banners, scratch cards, and cashback rewards on qualifying transactions.
- **🔔 Audio & Visual Confirmation**: Native payment success audio chimes and interactive feedback animations upon successful settlements.

## 📲 Installation

To install the release build on an Android device:

1. Download the [`app-release.apk`](app-release.apk) file from this repository or the Releases section.
2. Enable **Install from Unknown Sources** in your Android device settings if prompted.
3. Open the APK file on your device and tap **Install**.
4. Launch **Sudan UPI** and start transacting!

Alternatively, install via ADB:
```bash
adb install -r app-release.apk
```
